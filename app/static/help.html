Tutorial

Start tracking applications in five minutes

Open dashboard

1. Open InternTrack

After the app is running, use the dashboard link:

http://localhost:8000/

If InternTrack is deployed online, use the public URL from your hosting provider instead.

2. Add your first application

  1. Select New application.
  2. Enter the company, role, status, application date, and optional deadline.
  3. Add the job link in Source URL so you can find it later.
  4. Select Save.

3. Keep the pipeline current

Use statuses consistently:

  • Saved: interesting job you have not applied to yet.
  • Applied: application submitted.
  • Interview: active interview process.
  • Offer: offer received.
  • Rejected or Withdrawn: no longer active.

4. Filter, sort, and export

Use the status filter, company search, and sort controls to focus the table. Select Export CSV to download your applications for spreadsheets or backups.

Deploy for everyday use

After this PR is merged into GitHub, use the Render deployment link in the README. Render will ask you to connect GitHub and create the web service plus PostgreSQL database from the included blueprint.
